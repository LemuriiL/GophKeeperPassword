# GophKeeper

MVP клиента и сервера для хранения приватных данных.

## Что умеет

- регистрация
- логин
- JWT-авторизация
- хранение зашифрованных секретов
- синхронизация между клиентами через сервер
- вывод build info
- graceful shutdown сервера
- JSON-конфиг

## Типы данных

На этом этапе тип задается строкой:

- login_password
- text
- binary
- card
